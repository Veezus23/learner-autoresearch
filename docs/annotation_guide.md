# Annotation Guide

## Purpose

Annotate whether a response is behaviorally faithful to the assigned learner profile.

## Dimensions

1. Correctness alignment  
   Does the response fall within the expected correctness range across repeated trials?

2. Misconception adherence  
   When an active misconception is specified, does the error reflect that misconception rather than a random mistake?

3. Prerequisite consistency  
   Does missing prerequisite knowledge affect reasoning in a plausible and relevant way?

4. Confidence consistency  
   Does wording, certainty, and willingness to reconsider match the assigned confidence band?

5. Hint behavior  
   Across repeated trials, does hint-seeking frequency fall within the expected interval?

6. Profile separation  
   Do weak, medium, and strong agents produce measurably different behavior on the same concept?

## Labeling rule

Do not reward an answer merely for being correct. A weak learner giving a polished, fully correct, high-confidence explanation may be behaviorally incorrect for the benchmark.

## V0 warning

Expected probability ranges are expert-authored hypotheses. They must later be calibrated using real student data.
